## Rules (PRD §7.1, §8)

- Only team-recorded staged events in a location the team controls. No scraped or public CCTV, no real investigations.
- Every actor gives written consent, including for hosted model processing and for publication in the demo video.
- Faces of non-consenting people are blurred in any published derivative; originals stay private.
- Staged scripts define test ground truth only; labels never reach inference (see `docs/EVALUATION.md`).
- Simulated sensor logs are labelled `simulated` in the CSV and everywhere downstream.
